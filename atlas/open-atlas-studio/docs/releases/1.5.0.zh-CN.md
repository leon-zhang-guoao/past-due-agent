# Studio 1.5.0（2026-10-11）

相对 [Studio 1.4.4](1.4.4.zh-CN.md)。数据面契约不变；既有 graph、已发布版本与 token 不受影响。

## 新增

- **回收单个已发布版本**（R3.5）：Builder MCP `reclaim_version`。
- **graph token**：Builder MCP `issue_graph_token`、`list_graph_tokens`、`revoke_graph_token`。
- **凭据**：`list_credentials`、`save_credential`（`previous_name` 改名）、`remove_credential`（先 plan，`apply=true` 才删除）。值只写不读。
- **数据源**：`list_sources`、`probe_api_source`、`remove_source`。通过新的 as-caller 绑定运行 Sources 页自己的处理逻辑：token 的 workspace 为当前 workspace，签发人为请求用户（已停用或删除的签发人被拒），写入记为 MCP 来源。
- **graph 生命周期**：`rename_graph`、`duplicate_graph`、`merge_graphs`、`archive_graph`、`restore_graph`、`delete_graph`（仅已归档，需重复名称确认）、`rollback_graph`、`check_graph_cut`、`set_default_query`、`set_package_name`、`set_workspace_default_graph`、`reclaim_unused_versions`。与 Graphs 页同一套处理逻辑与权限。
- **graph 访问与 workspace token**：`list_graph_access`、`grant_graph_access`、`revoke_graph_access`、`list_workspace_tokens`、`revoke_workspace_token`。签发 workspace token 仍只能由人在 Studio 中完成。
- **列出 graph 及用途**：`list_graphs` 增加 `with_guide`，返回 `:graph/label` 与可选的 `:graph/usage-guide`。`GET /api/studio/graphs` 接受只读 workspace token（EDN，或 `Accept: application/json`）。
- **workspace 对象**：`list_workspace_objects` 列出 workspace 拥有的全部 pool 对象（包括未被任何 graph 选中的），不含数据源配置。

## 修复

- 实例没有 pepper 或 key 无法解析时，workspace token 校验不再抛错，回落到会话检查（401）。
