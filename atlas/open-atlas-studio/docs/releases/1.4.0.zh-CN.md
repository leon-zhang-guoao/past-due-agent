# Studio 1.4.0（2026-10-08）

## 变化

- **默认 HTTPS**：Builder（9631）与数据面（9632）首次启动时在 `$OPEN_ATLAS_STUDIO_HOME/tls/`
  生成自签证书并共用；开启 TLS 的监听器只接受 HTTPS。
- **自有证书**：`OPEN_ATLAS_STUDIO_BUILDER_TLS_KEYSTORE` / `_PASSWORD`（PKCS12），数据面默认沿用；
  数据面单独用一张设 `OPEN_ATLAS_STUDIO_DATA_TLS_KEYSTORE` / `_PASSWORD`。
- **反向代理**：`apps/studio/compose.yaml` 新增 `proxy` profile（Caddy，可用 Let's Encrypt）。
- UI 与启动横幅给出的数据面地址随 scheme 变为 `https://`；镜像健康检查兼容 HTTPS。
- Server：`OPEN_ATLAS_SERVER_TLS_KEYSTORE` / `_PASSWORD` 可开 HTTPS（默认仍为 HTTP）。

## 升级注意

- 原来写着 `http://…:9631`、`http://…:9632` 的 MCP 客户端配置与脚本要改成 `https://`，
  并信任自签证书（导出方法见 `docs/help/builder-mcp.md`「HTTPS 与证书」）。
- 保持明文 HTTP：设 `OPEN_ATLAS_STUDIO_TLS=off`。
