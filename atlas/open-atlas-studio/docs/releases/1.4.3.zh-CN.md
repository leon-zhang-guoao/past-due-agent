# Studio 1.4.3（2026-10-10）

相对 [Studio 1.4.2](1.4.2.zh-CN.md) 的补丁版本，无接口与数据变化。

## 修复

- **SSO 丢失 state cookie**：登录开始时先跳转到 redirect URI 的来源，在 localhost 打开的浏览器
  不再因 IdP 回到 127.0.0.1 而丢失 state cookie。被拒绝的回调在浏览器中显示可返回的页面，
  不再是渲染为空白的 EDN。
- **Graphs 页误报为空**：workspace 的图列表加载完成前显示 “Loading graphs…”（不显示数量），
  而不是 “No graphs yet”。

## 改进

- **Token 列表排序**：workspace token 与 graph token 列表按创建时间最新在前，历史记录在下方。
