# Studio 1.4.2（2026-10-09）

相对 [Studio 1.4.1](1.4.1.zh-CN.md) 的补丁版本，无接口与数据变化。

## 修复

- **切换 workspace 后不刷新**：Team / Sources / Variables / Tokens 在服务端完成切换之前就重新读取，
  拿到旧 workspace 的数据或失败（Sources 停在 “reading the register…”），之后不再重读。
  现在等服务端确认切换后再刷新。

## 新增

- **显示版本**：页脚左侧显示 `Studio <版本>`，悬停可见 commit 与构建时间（读自镜像 / 包中的 `BUILD.json`；
  开发检出显示 `dev`）。
