# Studio 1.0.0（2026-10-06）

提交 `be8d21f0` · 镜像 `open-atlas-studio:1.0.0`

## 变化

- 独立镜像（JRE），不再与 Workbench、Dossier 共用 `open-atlas-mac`（doc 110 §110.1）。
- 数据面新增 `GET /meta/contracts`，返回本构建的版本、提交号与所提供的契约；不从构建包启动时以
  `:build/info-absent` 拒绝（§110.3）。
- 启动日志第一行打印 `open-atlas studio <版本> (<提交>)`。
- 起号 1.0.0（§110.5）。功能与拆分前的 `open-atlas-mac:v1` 中的 Studio 相同。

## 契约

| | 上一版 | 本版 |
|---|---|---|
| 提供 | （未声明） | data-plane-api 1.0 · atlas-semantic 2.0.0 · artifact 1 |
| 要求 | — | — |

## 升级前提

无。备份 `data/open-atlas/studio`。

## 数据迁移

无。

## 升级步骤

部署目录 `.env` 中 `STUDIO_VERSION=1.0.0`，然后
`docker compose up -d --no-deps studio`。

## 验收

- `curl http://127.0.0.1:9632/meta/contracts` 返回 `1.0.0`、`dirty: false`。
- Dossier 经数据面 MCP 查询正常；Workbench 启动日志 `data plane contracts: compatible`。

## 回滚

镜像改回 `open-atlas-mac:v1`（命令保持 `[studio]`）后单独重启；无数据变化。

## 已知问题

无。
