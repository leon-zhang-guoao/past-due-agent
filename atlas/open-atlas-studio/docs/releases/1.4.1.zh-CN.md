# Studio 1.4.1（2026-10-09）

相对 [Studio 1.4.0](1.4.0.zh-CN.md) 的补丁版本，无接口与数据变化。

## 修复

- **Variables 编辑表单**：小窗口下表单底部的 Save / Cancel 被裁掉。表单改为名称与值并排、提示单行，
  高度约减半；空间仍不够时整个面板滚动而不是裁切。
- **Publish 页长列表**：
  - Access tokens 默认只列有效 token，已吊销 / 过期的收在 “Show revoked/expired (n)” 后；
  - 版本历史默认显示最新 5 个及正在服务的版本，“Show all N versions” 展开全部。

## 文档

- 新增帮助文档 [Workspace 角色与权限](../help/workspace-roles.zh-CN.md)：owner / editor / member 各能做什么及对应拒绝代码。
