# studio/version — B5b

[退出条件](../../../docs/design/80-build-plan.md)四条：

1. **体检任一条不过则切不出版本**；
2. **钻石冲突被拒绝**（R3.4）；
3. read 默认幂等而可 retry，**mutation 未声明幂等则拒绝带 retry 的版本**（E6.2）；
4. **真实边界 conformance**：同一 graph 版本经**池投影**编译的 env ⟷ 经**正式制品装载**
   编译的 env **等价**（[D4.10](../../../docs/design/40-artifacts.md#d410-conformance两层都必须等价)）。

## 裁定

### ① 密封不自己写，调 B3 的两个纯函数

[D4.10-a](../../../docs/design/40-artifacts.md#d410-a-编码与密封是两个纯函数b3-与-b5-共用)
明说 `encode_content` 与 `seal_graph`「B3 与 B5 共用」。本模块**一行序列化都不重写**——
重写等于给 content-hash 造第二个来源，而 content-hash **就是**内容身份
（[D4.3](../../../docs/design/40-artifacts.md#d43-三种身份分开content-hash-覆盖整份-contentedn)）。
两个来源迟早给出两个身份，那时「这两个版本是不是同一个东西」变成不可判定。

### ② 切版本 = 投影 → 闭包 → 体检 → 密封，**四步串行，前一步不过不进下一步**

投影是 B5a.2 的纯函数，**这里不重新实现，也不绕过**。体检跑在**投影产物 + 闭包**上,
不是跑在池上：体检要判的是「**这个版本**长什么样」，而池里还有一堆不属于这张图的东西。

### ③ 体检的两类结果**不能混**：拒绝 vs 展示

[D2.11](../../../docs/design/20-dialect.md#d211-切版本体检强化) 把它们分得很清：

| 拒绝 | 展示（质量指标节） |
|---|---|
| 结构（dangling input、link 断链、多方产出、传递引用冲突） | description 覆盖率 |
| D2.2 属性声明漂移 | synonyms 覆盖率 |
| D2.8 分页声明与 `:allowed` 子集 | `:format :code`/`:id` 的 `:values` 覆盖率 |
| E6.2 韧性（超时可强制、retry 的幂等性已知） | carried-only 键使用清单 · 档位分布（S5.4） |

**质量指标只展示不拒绝**是裁定过的，理由写在 D2.11 里：**社会压力够用**——没人想切出一个
报告上写着「40% 属性无描述」的版本给别人引用；**强制阈值会催生垃圾描述凑数**。
实现上这意味着两者走**两条路**，不许让指标复用拒绝的通道「顺手也拒一下」。

- [D3.5](../../../docs/design/30-workspace-graph.md#d35-版本在-graph-层对象无版本演化靠新增)：
  **原地修改过的对象清单**（同 id 内容 hash 对比）。它是「语义变更 vs 兼容修复」这条**没有
  机器判据**的纪律的唯一一只眼睛——悄悄改一条 WHERE 由此可见。
- [D5.1](../../../docs/design/50-security.md#d51-三档分类默认-public)：**本次新增、且继承了
  缺省 `:public` 而非显式声明**的属性单独成节。缺省翻转之后「忘了标」是**无声**的，
  而切版本是数据离开平台前的最后一道门——这一节是把无声换成「每次发布都出声」的唯一位置。
- [D5.5](../../../docs/design/50-security.md#d55-引用时确认带入档位上限只能压低不能抬高)：
  **引用带入的 `:restricted` 属性清单**——即便上限已经挡住了它们，清单也照列：
  挡住是当前配置的结果，**上限改一个字就不再挡**。

三节都是「不看就会出事」的，与「新增/移除了哪些属性」那种普通差异不同等。

### ⑤ 真实边界 conformance 是**测试套件的一等公民**

D4.10 原话：「两层都是测试套件里的一等公民，**不是『上线前记得手工比一次』**」。

所以它是一条常跑的自动化测试，装料用 **demo 模型**（[`fixtures/demo/model.edn`](../../../fixtures/demo/README.md)）：同一张图，一边走
池 → 投影 → 编译，一边走 池 → 投影 → 密封 → 制品 → 装载 → 编译，两个 env 对同一批 EQL
给出**逐字相同的结果、相同的 index 形状、相同的档位过滤行为、相同的失败分类**。

**它守的缝与 B3 那层不同**：B3 证的是「序列化不改变模型」，这一层证的是
「**池投影本身没走样**」——[D1.5](../../../docs/design/10-platform-boundary.md#d15-自测走制品不走池投影)
要的那道保障。

### ⑥ 两笔债在这一片到期

- **搜索索引键控**：[common/search README 裁定 ④](../../common/search/README.md) 记着 B4.3
  用的是**池 revision**，而 [D7.11](../../../docs/design/70-consumption.md#d711-语义层的呈现与搜索词条是文档洪泛在结构上解决)
  要的是 **graph 闭包 revision**（字典是钉版本引用，闭包 hash 天然覆盖；字典升版则索引整体
  作废重建，不存在「属性文档新、词条文档旧」的撕裂态）。**闭包 revision 在这一片第一次
  存在**，债到期。
- **D3.10 限定名不可变的另一半**：[B5a.1](../graph/README.md) 做成了「登记即不可变」并注明
  「B5b 若要放开是**加**一个查过版本的函数，不是放松那里」。这一片有了版本，那个函数
  该出现了——**且它只能放开「还没切过任何版本」这一种情形**。
