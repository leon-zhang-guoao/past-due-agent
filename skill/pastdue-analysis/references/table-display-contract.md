# Display contract — 3.2.0

Fixed facts are returned by Atlas; the Agent relays content-markdown, not individual cells.
Standard order: run info → monitor Country blocks → each Country overview/ranking → Country Vendor summary → all Vendor detail blocks → cross-Country → execution/evidence scope.
The unique assembly protocol is `report-format.md`; payload identity/check rules are `fact-block-contract.md`.

## Fixed blocks
- Country metrics use monitor-block content; historical context uses actual event facts.
- COUNTRY_OVERVIEW includes fixed Country metrics, Vendor ranking and selected coverage.
- VENDOR_DETAILS includes metrics, Code/Source Top5+Other, signed totals and rule-based Code signals.
- Conditional Code=US Source evidence supports Country narrative, not a standalone table.
- No model-issued report PASS; final output is NOT_INDEPENDENTLY_VERIFIED without independent evidence.

## Compatibility
Older module definitions in EDN document structured audit/interactive columns only. They are not an alternative default report renderer. Flexible analysis remains composable; explicit custom output declares its scope.
