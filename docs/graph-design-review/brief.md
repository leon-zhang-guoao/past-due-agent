平台、权限、指标负责人、可信参考与真实验收仍待核实，不因本地实现视为确认。

## 1. 目标

- 图：既有 PastDue 图的兼容扩展，保持 Prompt + Skill + Atlas 部署。
- 使用者：需要按 Country、Vendor、ETA、组织查看逾期的业务人员；具体部门和角色待负责人登记。
- 支持决策：日常监控、定位增长来源、比较分布、查看改善与风险、按需查看当前 PO。
- 本轮目标：把选择、排名和展开的重复机械工作放入图，减少模型复制参数和搬运集合。
- 业务负责人、IT 联系人：未在现有资料中确认，见 open-items.md。

继续使用图现有绑定，不新增连接；本文件不记录主机、账号或凭据。

| past_due.vendor_past_due_daily | 按日期、Country、Vendor、ETA 的历史计数 | 完成日期规则不证明 ETL 所有分区已齐；实际刷新与唯一性未在线核实 |

## 4. 定义

- 指标、日历、时区、阈值、标准日报选择继续沿用
  [metric-definitions.md](../../skill/pastdue-analysis/references/metric-definitions.md)。
- 本次不重新定义 PD、Open、贡献、比例、Code 含义或负责人责任。
- 提议增加显式选择语义：排名对象、排名分区、选择条件与展开条件分别表达。
- FILTERED_POPULATION 分母按候选 Vendor + 组织范围计算，在排名截断前固定；
  ETA 条件与 Top N 不自动缩小该分母。选择结果的构成比例如另有需要，应另行定义，
  不重用旧字段改变含义。
- 新选择语义尚待确认；指标负责人姓名未知，不新增 certified 声明。

## 5. 访问规则

沿用实际部署的授权 Country、行和字段权限；用户输入的 Country 过滤不能代替授权。

权限机制及实际角色测试需 IT 提供，不以离线 SQL 通过推定。

## 6. 用语

Country／国家，Vendor／供应商，Past Due／逾期，ETA Code，Source，
当前／CURRENT，快照／SNAPSHOT，两期／PAIR，区间逐日／RANGE。
“最多”按当前问题和上下文识别；“恶化”涉及数量、比率或贡献的实质歧义时澄清。
